3. Software

Software produces carbon through the electricity it consumes across the phases of its lifeycle, from development through to testing and operation. It also indirectly produces carbon through the embodied impacts of the hardware it runs on.

Metrics to track with software

Energy use can be factored into a service carbon footprint calculation and estimations of carbo. See page on that LINK

Using proxies for estimating the energy used by software

In order to help guide us and understand the direction of some of our actions, proxies can be used, but NOT to inform the overall SCI measurement?

Where direct measurement to inform energy usage metrics is not possible, there are a number of proxies that can be used to provide an estimate, such as:

RAM Consumption & Server Count Using hardware footprint or active node counts as a baseline for operational and embodied carbon.
Data transfer This approach has often used for websites by take the weight (in bytes) of web pages and multiplies this by an estimated energy-per-gigabyte factor uses this to estimate the carbon emissions from the transfer of this data to the end user A number of online webpage carbon footprint calculators use these methods but this 'data transfer' approach is more appropriate for standalone websites rather than complex service. Software development standards in Defra

For software development in Defra: https://digital.defra.gov.uk/software-development defra service manual

In defra, there are standards on the software frameworks and languages to use - see this guidance on that!

Defra software delivery standards - https://defra.github.io/software-development-standards/

These form part of the software development standards policy for Defra and apply to all software development undertaken on behalf of the Defra group whether by staff, contingent workers or suppliers. All developers working on behalf of Defra need to be aware of their obligation to follow these standards. Any deviation must be managed as an exception under Defra's architectural governance processes.

Defra standards have coding standards for a range of software languages.
