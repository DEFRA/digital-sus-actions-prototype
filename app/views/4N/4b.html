4b. Take a circular approach to architecture

Making use of existing architectural components, and sharing new ones when these are created, helps save on the resources consuemd with developing new ones.

Lead role families: Architecture
Likely co-benefits Cost: Lower costs coming the storage of data

(i) Build with existing, modular architectural components

Architectural components define the high-level blue-prints, capabilities, and structural boundaries of a software system.

Using existing, proven, components saves on the resources associated with developing and testing these from scratch.

See also 2a. Software

(ii) Share components via a library

A component library is a collection of re-usable components, helping teams make use of those created for other projects.
