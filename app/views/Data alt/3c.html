(i) Compress data for transit

Compressing data in transit reduces payload sizes, helping reduce network load and energy consumption.

Co-benefits and trade-offs

Compressing data for transit can bring co-benefits in terms of:

  • Lower infrastructure costs: 'Cold' or archive storage tiers are usually cheaper that warmer ones

(ii) Enable consumption of data from primary source

Consuming data from its primary source means accessing data from where it was first generated.

This means we can access the most up-to-date information without the need for any intermediary processing or transformation. This reduces data processing, storage and network transmission energy.

(iii) Use efficient protocols

A network protocol is a set of rules that define how data is exchanged between devices on a network. Using efficient protocols like UDP based HTTP3 or QUIC can help reduce retransmissions.
