Software Carbon Intensity (SCI) for Web

1. Using page weights as a proxy for carbon

There are a number of methods, , that take the weight (in bytes) of web pages and uses this to estimate the carbon emissions from the transfer of this data to the end user. This means taking data transfer as an proxy indicator for total resource usage, and using this number to extrapolate energy usage as a fraction of the energy used by the total internet system. A number of online webpage carbon footprint calculators use these methods. This 'data transfer' approach is more appropriate for standalone websites rather than complex services, as it focused on the front end and does not consider what is going on on the ‘back end’, with hosting and databases for example.
